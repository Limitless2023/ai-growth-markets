方法论 · Methodology

Our credibility rests on this page. Key rules are bilingual; full text is maintained in docs/methodology.md.

1. The Number 怎么算 · How The Number is computed

The Number = 账本中同时满足以下五个条件的事件的岗位数之和：

  1. status == "published"（已经过人工终审发布）
  2. counted == true
  3. confidence == "company_stated" —— 只计当事方亲口宣布的数字，机构估算永不入账
  4. kind 为「招聘承诺」或「新建团队」
  5. 岗位数为明确的正整数（没有数字的事件入账本、不入计数）

The Number is the sum of jobs_count over events that are published, counted, first-party stated (company_stated), of kind hiring commitment or team formation, with an explicit positive integer count.

The Number 是一个"可逐行核查的保守下限"，不是对全球 AI 岗位创造总量的估计。 我们的数字比 LinkedIn 的 130 万小得多——但每一个都能点开看到来源原文。

It is a verifiable, conservative floor — not an estimate of total AI job creation. Our number is far smaller than LinkedIn's 1.3M, but every unit of it links to a source.

2. 入选标准 · Inclusion criteria

账本记录的是「谁、在什么时候、宣布了什么」，不是我们对"什么算 AI 创造的岗位"的判断——这个定义争议被有意外包给来源。

We record who announced what, when — the definition of "AI-created" is deliberately outsourced to the source itself.

kind含义 · Meaning可否入账 · Counted?
hiring_commitment公司/政府公开宣布因 AI 新增 N 个岗位 · First-party hiring pledge✅ 满足五条件时
team_formation新设 AI 相关部门/团队 · New AI team/unit✅ 满足五条件时
official_listing官方新职业认定 · Official occupation listing❌ 永不
report_datapoint机构报告数据点 · Institutional datapoint❌ 永不（仅参照系）
  • ✅ 收录：来源原文明确把新增岗位/团队/职业归因于 AI
  • ❌ 拒收：无公开来源、仅付费墙、传言；来源没说 AI、由我们推断的事件

3. 双轨展示 · Two tracks, never added together

账本轨（事件级、逐行带来源、保守下限）与参照轨（LinkedIn 130 万、WEF 净增 7800 万预测、人社部 110 个新职业等机构口径）结构上不可能混加——数据校验层禁止机构口径事件入账（规则 R4）。

各招聘平台数据（BOSS直聘 +74.1%、脉脉 +543% 等）统计基数互不相同，不可互相比较或加和；每条事件的口径备注写在 notes_zh。

4. 已知局限 · Known limitations

  • 承诺 ≠ 到岗：账本记录公开承诺，企业可能夸大或不兑现；回访核查机制在路线图 P2。
  • 覆盖偏差：以中英文公开报道为主，其他语言区与不发新闻稿的中小企业被系统性低估。
  • 日期精度：部分报告仅精确到月，按当月首日（月度统计取月末日）记录并在备注注明。
  • 建设期 vs 运营期：数据中心类公告分开记或取常驻岗，绝不取大数。

5. 纠错政策 · Corrections

发现错误请提 GitHub Issue（指明事件 id 与问题）。核实属实即修正，全部修订通过 git 历史公开留痕；影响 The Number 的重大更正在 README 更正日志记录。

7. 更新管线 · Update pipeline

信源登记表 → collector agent 扫描 → 候选草稿（PR）→ 人工终审 → 发布 → The Number 自动更新

人工终审是可信度底线：本项目永不全自动发布。 Human review is the credibility floor: nothing publishes automatically.
